# A neural network built from scratch using only NumPy to classify cats and non-cats.

## Description

It has been implemented without using AI frameworks like PyTorch or TensorFlow. All the steps, including Backpropagation, have been implemented manually

The model is trained on the dataset provided in course-1 of
the Deep Learning Specialization taught by Andrew Ng

The training set contains 209 images, 64 X 64 X 3 in size
\
The model, after training, averages 98% accuracy on the training set,
and varies between 56% - 80% on the test set, averaging to a 72% accuracy

I have attached the cost graph

## Features
- Forward propagation
- Backpropagation
- ReLU and Sigmoid activations
- He initialization
- L2 regularization
- Gradient descent

## Architecture

No. of units:-

12288 → 10 → 6 → 4 → 1

## Results

Training Accuracy: ~98%
\
Test Accuracy: Average 72% (varies between 56% - 80%)
